# Deployment administrator, Owner or Gateway client using System token or Gateway client using Account token or Member using Access policy may read Model metadata

Deployment administrator and Owner save reference metadata and pricing. Personal catalogue and inference consult only the models relevant to their applicable access and execution. Configured catalogue refresh may update its owned metadata as a bounded/manual or due scheduled continuation, preserving manual/catalog ownership.
