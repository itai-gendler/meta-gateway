# Deployment administrator, Owner or Gateway client using System token or Gateway client using Account token or Member using Access policy may read Route

Deployment administrator and Owner manage Routes. Applicable personal and inference access consults their current eligible model pool. Automatic discovery may create or update bindings for the actual configured enabled connection in Auto mode; Manual refresh changes candidates only. Pattern precedence, mapping and eligibility continue to govern the selected route.
